# HomeClock 1.1.1

Corrección de contraste sobre la 1.1.

## Cambios

- La ciudad del bloque de tiempo pasa de 30sp a **32sp** y de `#808080` a
  **`#B0B0B0`**, con mejor contraste sobre el fondo negro.
- Sin cambios funcionales: se mantienen las varias ciudades, el swipe, la
  ciudad actual por IP, el diagnóstico persistente y la carga de As Celtas.

## Instalación

```bash
adb install -r homeclock-1.1.1.apk
```

Misma firma y `applicationId`; actualiza encima de la 1.1 sin perder ajustes,
ciudades ni diagnóstico.
